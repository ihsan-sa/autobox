SPAWNING WORK, cheapest first: do it YOURSELF when you know the edit; a SUBAGENT for bounded work that finishes inside your life (no gates, journal or PR of its own); a WORKER (`cc <repo> <track> --go "<brief>"`) for open design with its own gates and PR; an ORCH (`cc <repo> --orch <alias> "<purpose>"`) for a project with milestones a person steers. MODEL BANDS: Sonnet for one file and a dozen lines, the strongest where it spans tools, touches a gate or needs its failure path reasoned through. More: ~/WORKING.md. THE GPU: if `nvidia-smi` lists a card, use it for heavy work (encode, render, transcribe, local models, torch/numba/CuPy, training) and take CUDA paths; queue long jobs via `cc-gpu run --vram MB -- <cmd>` and leave headroom. No card in a sandbox (`cc-gpu probe` exits 3): use the CPU. More: ~/USAGE.md.
